# Game design reference

## Rarities
Common 20, Uncommon 14, Rare 10, Epic 7, Legendary 4, Mythic 3, Genesis 2 (60 critters). Mythic and Genesis only come from packs.

## Economy limits (per UTC day)
Minigame coins 400, Arena coins 400, Meadow (background) coins 40, Arcade tickets 6. Duplicate refunds: 4 / 12 / 30 / 80 / 220 / 600 / 1500 coins by rarity (x3 for shiny). Every paid pack refunds under 90% of its price even if all cards are duplicates.

## Levels
XP to next level = 30 + 20 x level. Each level adds 3.5% to HP, Attack, Defence and Speed. Max level 30.

## Minigame rewards
Stars from the goals shown in each game. Coins 2 / 10 / 20 / 36, buddy XP 3 / 8 / 14 / 22, tickets 0 / 0 / 1 / 2 for 0 to 3 stars. The featured game of the day doubles coins and XP and adds a ticket.

## Battles
Damage = ((Attack / Defence) x power x 0.5 + 2) x type effect x same-type bonus x roll (0.9-1.1) x critical (1.5x). Type effect: 2x strong, 0.5x weak, multiplied for dual types. Stat stages -2 to +2 (25% each). Passives: Stampede (bull), Thick Fur (bear), Wave Rider (whale), Night Eye (moon), Armor Plating (vault), Fresh Leaf (mint), Static (spark), Mist Cover (fog). Statuses: Stunned (25% to lose the turn, 3 turns), Rugged (1/8 HP per turn, 4 turns). Foe level = round x 3 - 2, Easy -2, Hard +3, boss +2.
